## 📌 About the Project

This is a modern, responsive personal portfolio website developed as part of **Task 2**.

The project demonstrates advanced CSS3 concepts including **CSS Variables, CSS Grid, Flexbox, responsive design, media queries, dark mode, hover effects, and accessibility features**.

The website is designed with a modern **Purple & Lavender** theme and is optimized for mobile, tablet, and desktop devices.
